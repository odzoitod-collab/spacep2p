# Strait Pay — канон бренда

## Имя
* Всегда **Strait Pay**: два слова, заглавные S и P. Не «STRAIT PAY», не «StraitPay», не «Страйт Пэй».
* В коде — константа `BRAND` в `bot/ui.py`. Не пишите имя вручную в текстах.
* Слоган — `TAGLINE`: «P2P-обмен USDT ⇄ RUB с защитой сделки».

## Где бренд виден
| Место | Как |
|---|---|
| Главное меню | заголовок **Strait Pay**, под ним курсивом слоган |
| Профиль бота в Telegram | описание и короткое описание (ставятся при запуске, `commands.DESCRIPTION`/`SHORT`) |
| Меню команд | `/start` — «Strait Pay: главное меню», `/api` — «API для сервисов» |
| Помощь | «Помощь · Strait Pay» |
| Счета и чеки xRocket | «Пополнение баланса Strait Pay…», «Вывод с баланса Strait Pay» |
| API | раздел «Strait Pay API», `GET /` → `{"name": "Strait Pay API"}`, вебхуки с `User-Agent: StraitPay-Webhooks/1.0` и заголовками `X-Strait-*`, токены `sp_live_…` |
| Документация | `docs/API.md`, отдаётся по `GET /docs` |

## Голос
* Коротко и по делу: что произошло → что делать дальше. Без канцелярита и восклицаний.
* На «вы». Термины: «сделка» (в боте), «заказ» (в API), «продавец/мерчант», «покупатель», «чек», «спор».
* Деньги — с единицами: «10 000 ₽», «94 USDT». Разделитель тысяч — пробел.
* Предупреждения — только когда есть риск потерять деньги (неверная сеть, перевод без чека, отмена после перевода).

## Вид экранов
Каждый экран: иконка + **заголовок** → строка статуса → цитата с цифрами → следующий шаг → итог действия
(✅ или ⚠️). Навигация («Назад», «В меню», «Отмена») — всегда одна последняя строка кнопок.
* Поле — **«Подпись:» значение**: строка «• Подпись: значение» в цитате (`ui.quote`) сама становится полем с
  жирной подписью; список не смешивает поля и пункты «•».
* Раздел внутри экрана — `ui.section(icon, текст)`: заголовок отдельной цитатой с иконкой.
* Админка и логи — карточный стиль `ui.cf(подпись, значение…)`: подпись цитатой, значение строкой ниже на ветке
  (`╰`, для нескольких — `├ … ╰`). Люди и номера — ссылки на их карточку в боте (`ui.ulink`, `ui.alink`), внизу
  дата курсивом (`ui.stamp`), решение — строкой вердикта «✅ Одобрено · имя» (`ui.verdict`).
* Пояснение к экрану — цитатой в конце; пусто — «<i>Пока пусто.</i>».
